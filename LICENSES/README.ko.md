# 라이선스

코어마다 원본 라이선스를 그대로 따르고, 이 저장소의 패치도 같은 조건이에요. 원문은 이 폴더에 있어요.

| 원본 | 파일 | 조건 |
|---|---|---|
| melonDS DS | `melonds-ds_LICENSE` | GPL-3.0 |
| DSperate | `DSperate_LICENSE` | GPL-3.0 |
| gambatte-libretro | `gambatte-libretro_COPYING` | GPL-2.0 |
| mGBA | `mgba_LICENSE` | MPL-2.0 |
| gpSP | `gpsp_COPYING` | GPL-2.0 |
| Beetle WonderSwan | `beetle-wswan-libretro_COPYING` | GPL-2.0 |
| Beetle NeoPop | `beetle-ngp-libretro_COPYING` | GPL-2.0 |
| Genesis Plus GX | `Genesis-Plus-GX_LICENSE.txt` | **비상업** · 고친 판은 소스 전체 공개 |
| blueMSX | `blueMSX-libretro_license.txt` | 파일마다 다름(BSD 계열 · GPL · zlib 등) |
| FCEUmm | `libretro-fceumm_Copying` | GPL-2.0 |
| DOSBox Pure | `dosbox-pure_LICENSE` | GPL-2.0 |
| MAME 2003-Plus | `mame2003-plus-libretro_LICENSE.md` | **비상업**(MAME 옛 라이선스) |
| FinalBurn Neo | `FBNeo_src_license.txt`(+ `FBNeo_LICENSE.md`) | **비상업** · 소스 고침 공개 · 원문 그대로 함께 |

**비상업** 표시된 코어는 돈을 받고 팔거나, 파는 기기에 넣으면 안 돼요.
